## Requirement collaboration brief

- Parent summary：父卡 038 已登记用户 2026-10-23「按 harness 开发，web 和 android」的实现授权；人设规格 `Docs/spec/SPEC-2026-09-21-ai-persona-preference.md` 的界面方案与 2026-10-23 拍板（未知档回落默认并提示、切换不刷新活动时间）对两端同时生效。Android 侧已在 064/066/067 落地，本片只做 Web。
- Problem/background: Web 工作区目前没有任何人设概念（`frontend/src` 全量扫 `persona|Persona|风格` 零命中），聊天输入行只有模型 chip；设置页只有采集夹具的只读分类。父卡要求 Web 同步交付人设视图，且 Web 是只读 parity 演示：不伪造生成数据，人设选择只落在会话内主题级本地状态。
- Users/scenarios: 学习者在 Web 聊天页输入行点人设 chip，弹窗七行里换档，换档反馈只提示一次；想看清七档差异时从弹窗底行或设置页入口进入静态介绍页。
- Expected outcome: 聊天输入行模型 chip 右侧出现同款人设 chip（当前档名 + 下拉箭头）；点它弹出跟手小弹窗：顶部 label「回答风格」、七行档名、当前档对勾与选中底色、底部分隔线 + 「了解每种风格」；介绍页七张卡（档名、一句话定位、静态示例）+ 页脚说明；设置页出现「回答风格介绍」小节与入口行；切换只改该主题的会话内档位并给一次提示，不写任何持久化、不改夹具数据。
- Core flow and reversibility: `Composer` 新增可选人设槽 → `PersonaPicker` 弹窗 → `setTopicPersona(topic, wireId)` 写 `store/workspace.ts` 的会话内映射 → chip 与弹窗重读；弹窗底行与设置入口走 `openView("persona-intro")`；介绍页返回走既有 `back()`。全程不触碰夹具、不发请求、不需要 API Key。
- Inputs/outputs: 输入是 `store/workspace.ts` 的主题下标与既有 copy 机制；输出是一处 chip、一个弹窗、一个静态页、一处设置入口与对应 copy 键。
- State and exception handling: 会话内映射缺省即「默认」档，chip 恒有档名、无空态；`personaFromWireId` 对未知 wire 值回落 `default` 并返回回落信号，界面按信号给一次提示（与 Android 064 同口径）；介绍页不依赖任何数据状态，断网可用。
- Constraints and trade-offs: 用户可见文案一律走 `copy/zh-CN.ts` + `useCopy`，过 `pnpm check:user-copy-i18n`；颜色只引 `tokens.css` 变量，过 `check_design_tokens.py` 的裸 hex 扫描；不新增依赖；不新增持久化；不动夹具与采集链路；可点区域不小于 44px。
- AI recommendation and rationale: 人设映射放进既有 `store/workspace.ts` 而不是新 store：它和 drafts 同属会话内 UI 状态，新增 store 会多一套订阅面；弹窗做成 `Composer` 旁的独立组件 `PersonaPicker`，保持 `Composer` 的「未接通语义」不被破坏——人设 chip 是唯一接通的动作，因为它不依赖后端。
- User choice and custom additions: 七档与档名、一句话定位、示例文案逐字取自 Android `strings.xml`（066/067 已按规格落地），Web copy 键名与 Android resource 名一致；切换提示文案同 `persona_switched`。
- AI-autonomous decisions: ① 弹窗相对 chip 绝对定位、恒向上展开（输入区在页面底部，不存在向下空间）；窄窗（<=760px）改以输入区两沿为锚展开，避免右侧出血到视口外，实测 390px 视口 left=24/right=366；② 切换反馈复用聊天页 `role=status` 的反馈行模式（浮在输入区上沿的胶囊，3 秒后自清）而不是新造 toast 基础设施；③ 介绍页作为 `WorkspaceView` 的新值 `persona-intro` 进入既有 hash 路由，返回链复用 `back()`；④ 设置入口以静态小节追加在既有夹具分类布局之后，不改夹具解析；⑤ 弹窗在玻璃层给不透明实色：它是 `.composer`（自带 backdrop-filter）的后代，背景模糊取不到弹窗区域的底，半透明会把正文读成噪声。
- User-confirmation decisions: 本片不新增需要用户拍板的产品决策；口径全部来自已 accepted 的人设规格与 2026-10-21/23 拍板。

- 人设映射落在既有 `store/workspace.ts`（与 drafts 同属会话内 UI 状态），不新增 store、不写 localStorage、不碰夹具；刷新即回「默认」是 Web 只读 parity 的既定口径。
