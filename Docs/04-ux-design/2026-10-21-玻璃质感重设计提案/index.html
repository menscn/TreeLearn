如果今天就要选

先确定主界面，再决定展示面。玻璃不是越透越好，阅读区必须留一层不透明的底线。

主推荐

A · 晨雾玻璃

作为默认主题落地。阅读区的对比最稳，最接近 iOS 的原生材质，也最容易从现有纸感迁移。先落 A，再用 B 的光斑和 C 的边缘高光做局部增强。

品牌强化

B · 青苔温室

留给发布会、Pad 展示和品牌页。青苔底与树冠阴影能把「生长」讲清楚；不建议直接作为长文主界面。

轻量展示

C · 浮光

适合封面、短内容和营销页。它最通透，但 72% 阅读区是下限，不应再往下调。

混合建议：A 的结构 + B 的一层树冠阴影 + C 的 1px 高光边缘。混合后仍沿用 A 的阅读底，不改变正文对比。

提案边界：三个方向页都是静态高保真演示，不修改 tokens.json、colors.xml、tokens.css 或任何 Android / Web 代码。选定方向后，数值仍需按「原型 :root → tokens.json → colors.xml → tokens.css → 守门」落盘。

依据：现有四屏 Android fixture 文案、Docs/04-ux-design 设计 token、ic_brand_sprout 官方芽形标识。浅色主题；深色主题不在本次范围。
