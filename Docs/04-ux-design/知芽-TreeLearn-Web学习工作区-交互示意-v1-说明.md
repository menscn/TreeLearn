# Web 学习工作区交互示意 · 2026-10-21

这是供评审的独立设计提案，描述拟议交互，不是正式 Web 的运行事实或已接受规格。

打开 [HTML 示意稿](知芽-TreeLearn-Web学习工作区-交互示意-v1.html) 即可体验，不需要安装依赖或启动服务。

## 范围与来源

- 用户已选择上一轮推荐的“轻量学习工作区”方向，本次只生成 HTML 示意。
- 展示左侧可折叠导航、居中限宽阅读、固定输入区、按需分支面板，以及主页、学习库、设置和知识树的可切换视图。
- 示例主题、完整回答、推荐问题、摘要和模型名静态摘录自 `frontend/src/platform/fixtures/*-android.json` 的既有脱敏快照；另一个主题只展示其已有摘要，没有编造回答。
- 色彩、字体和基础度量逐值镜像自 [现有原型](知芽-TreeLearn-高保真原型-v1.html) 的 `:root`，没有修改权威 token；SVG 采用现有 Web 图标对应的路径，并在示意稿中隔离命名。
- 正式 `frontend/`、Android、原型权威文件和用户原有工作区改动均未修改。正式运行时不会导入本提案。

## 可体验的交互与边界

- 切换主页、学习库、主题、设置；恢复主题阅读位置和当前页面内的草稿。浏览器返回可恢复阅读位置。
- 学习库支持按现有标题和摘要进行示意搜索，切换进行中／已完成，展开摘要。
- 分支导航默认关闭；宽窗口并排显示，较窄窗口覆盖显示，并提供遮罩、关闭和键盘退出。已有主题只有根分支；点击“创建分支”可在本次示意会话中添加子分支。
- 知识树展示当前示意会话的分支，可缩放和返回对应分支；没有伪造既有子分支。
- 输入支持 Enter 发送、Shift + Enter 换行，中文输入法选词不发送。发送仅展示输入和明确的示意提示，不调用 AI。
- 附件仅展示选择的文件名，不读取文件内容，不上传。设置保存仅演示状态反馈，不写入正式配置，不保存输入的密钥。
- 设置提供未保存提示和放弃修改确认；语音试听使用浏览器提供的系统语音能力，是否可播放取决于浏览器环境。
- 不连接远程服务，不使用正式应用存储，不承诺刷新后保留会话。
