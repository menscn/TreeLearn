数值**不允许**在本目录被重新定义：这里只镜像原型。四方一致性由脚本判定，不靠人眼：

```bash
python .codex/scripts/dev/gen_design_tokens_css.py            # 由 tokens.json 生成/刷新 tokens.css
python .codex/scripts/dev/gen_design_tokens_css.py --check     # 只判「已落盘的是否逐字节等于重新生成」
python .codex/scripts/dev/check_design_tokens.py              # 校验真实文件（四方 + 前端裸色值）
python .codex/scripts/dev/check_design_tokens.py --selftest    # 守门自身的正反双向自检
```

生成物只有一条变更路径：改 `tokens.json`（而 `tokens.json` 又要先改原型 `:root`）→ 重新生成 → 跑守门。手工编辑 `tokens.css` 会被逐字节漂移校验拦红，这是设计意图而不是不便。

| `fontSize` | `fs-display` `fs-h1` `fs-h2` `fs-body` `fs-sm` `fs-cap` | display 与 caption 拉开约 2.4 倍对比（26/11） |
| `shadow` | `sh-1` `sh-2` | 只保留两档 |
| `fontFamily` | `kai` `serif` `brush` `sans` | 正文走系统 `sans-serif`（`sans`）；品牌与页面主标题的衬线在 Web 侧走 `serif` 回退栈，Android 侧自 2026-10-22 起由随 APK 分发的 `Noto Serif CJK SC` 单字重承担（`res/font/noto_serif_sc.otf`，OFL）。**2026-09-27 起 `kai` 只剩 `.home-hero .hh-sub`（首页 hero 副标题）一处引用**：`.screen` 原为楷体、已改为 `sans`，因为对话页设计稿与真机 `themes.xml` 都是 `sans-serif`。`brush` 仍是题字用；`kai` 退役待定 |
| `other` | `lh-read` `glass-blur` `glass-saturate` `glass-shadow` | 阅读行高 28px，与纸感横格间距对齐；`glass-*` 是 2026-10-21 玻璃材质的模糊/饱和/投影参数 |

`hairline`/`paper-rule`/`paper-write` 与 `glass-*`/`glow-*` 是 rgba，Android 的 `colors.xml` 副本不收录。玻璃色与莫兰迪柔光的 Android 副本单独放在 `android/app/src/main/res/values/glass.xml`（8 位 `#AARRGGBB`），由 JUnit `GlassMaterialTokensTest` 读取 `tokens.json` 自动比对 alpha，不手抄数值。莫兰迪 `tint-*` 是不透明 hex，与 mist 一样进 `colors.xml`（`tl_tint_*`）。

## 怎么用

- **Figma 侧**：把本文件当作绑定的数值来源。写画布时用 `create_variable` 建变量、`bind_variable_to_node` / `bind_variable_to_paint` 绑定，**不要**在节点上写裸 hex/px。流程见 `.agents/skills/figma-build/SKILL.md`。
- **Android 侧**：实现界面时只从 `colors.xml` 取色，间距/圆角取 `space`/`radius` 档位。新增资源必须能反查到原型里的同名 token。
- **前端侧**：只从 `tokens.css` 的 CSS 变量取值（`var(--green)` 等），生产代码不得出现裸 hex；`frontend/src/**` 的裸色值由 `check_design_tokens.py` 扫描判 FAIL，且该分支带正反双向自检。变量名与 token 名逐字相同，不做第二次命名。
- **改设计**：先改原型 `:root`，再更新 `tokens.json`，然后同步 `colors.xml`，再重新生成 `tokens.css`，最后跑守门脚本。跳过任何一步都会被脚本拦下。
