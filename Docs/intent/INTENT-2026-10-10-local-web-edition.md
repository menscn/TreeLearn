## Problem（问题与背景）

- 问题/背景：当前生产产品只有 Android；用户需要在电脑启动本机服务后通过 localhost 使用浏览器，处理同样的树状学习任务。此前 Android WebView 迁移意图不包含浏览器正式端，无法直接满足这个场景。
- 用户/场景：在当前 Windows 电脑上阅读长回答、输入问题、查看知识树、管理模型与附件；两端数据独立。
- 不做的后果：电脑学习仍需要通过手机或模拟器使用 Android 界面，不能获得适合键盘、鼠标与大屏阅读的工作区。这是使用形态的差异，不是已测量的时间收益。

## Users and scenarios（用户与场景）

- 单人本地使用；打开服务提供的 localhost 页面即可进入学习工作区。
- 对话、稳定回答分叉、树导航、搜索、生成恢复、批注、文件与服务设置等能力保持与当前 Android 实际实现一致。
- UI 按 Web 重新组织；功能一致不要求复制手机的底部导航或全屏跳转方式。

## Expected outcome（预期结果）

- 最终软件：React + TypeScript 页面与本机 Java 服务，电脑本地持久化，不依赖手机或模拟器运行；两端不自动同步。
- 本轮产物：通过交互伴侣讨论的 HTML 原型、需求/交互规格、功能对照表、详细开发方案与 AI 交接入口；用户会交给其它 AI 执行开发。
- 已确认的主交互：A「专注阅读」为默认；B「并排分支」和 C「树图探索」是可切换辅助视图。
- 已确认的视觉：2026-10-10 用户提供的薄荷雾面配色，图标参考 v1.1 原型，使用 huashu-design 辅助设计。

## Core flow（核心流程）

- 核心流程：启动本机服务 → 浏览器打开 localhost → 配置可用 Provider → 新建主题并获得稳定回答 → 选文或整条回答分叉 → 沿来源返回或查看树总览 → 继续追问。
- 中断与恢复：刷新不重发命令；服务重启从本机持久化事实恢复；部分内容保留但不可分叉；重试和重置沿用手机版的原位操作与版本规则。
- 输入/输出：问题、引用、已支持的附件、语音识别草稿；输出为回答、推理、来源、分支、要点和用户批注。示例原型不调用模型或真实麦克风，不保存真实 Key。
- 状态与异常：可用、加载、无 Key、配置回落、正在生成、稳定、失败、中断、取消、服务不可用；每种异常提供可执行下一步，禁止误报保存或生成成功。

## Constraints and non-goals（约束与非目标）

- 约束：功能基准来自活动 Android producer/consumer；优先共享 Java 领域规则；Android 保持 Java-only；本机服务限定 loopback；密钥不进浏览器持久化、日志或聊天导出；实际时间使用 UTC epoch 毫秒，显示使用设备时区。
- 权衡偏好：接受 Web 与本机 Java 服务的构建成本，以复用规则、持久化恢复和大屏交互为优先。
- 非目标：两端同步、账号、公网/局域网远程访问、云数据库、Android UI 全面迁移、新模型原生协议、与当前功能无关的 Agent/RAG 平台能力。
- 本轮不把导入/导出、云备份或人设选择器从旧候选材料自动加入范围；若生产链路未核实，先明确差异。
- 本轮只做设计与开发输入，不执行生产开发、不建立 Harness 实现任务。

## Open questions（开放问题）

- 已确认事实：用户确认两端不同步、先完成设计和开发文档；用户选择 A 默认布局并指定新配色、旧原型图标和 huashu-design。
- 假设：Windows 为首发验证环境；Chrome/Edge 为首批正式目标浏览器。新增其它平台不影响领域规则，但需分别验证系统凭据和语音能力。
- 工程待证：共享 Java 构件接入、本机服务与 SQLite 驱动版本、系统凭据适配、语音识别覆盖和体积/性能。不能以原型模拟结果替代运行证据。
- 原型各页面细节可继续 review；主布局选择已确认，不再作为未决范围问题重复询问。

## Convergence verdict（收敛判定）

### 有价值吗

结论：是。
证据：用户明确提出电脑浏览器使用需求；当前生产源码与目录仅有 Android，桌面输入、长文阅读和树导航没有正式 Web 入口。

### 值得做吗

结论：是，先交付设计与开发输入。
证据：用户确认下一步并说明交给其他 AI 开发；本轮先收敛产品和交互能避免在 WebView 旧范围上继续实现错误交付。代价是新增独立运行时适配和浏览器验证。

### 可以做吗

结论：产品与设计范围可推进，生产可运行性须由后续开发验证。
证据：现有 `:core` 与 `:tree-layout` 是 Java library，提供复用基础；`GenerationCoordinator`、AI 装配、SQLite 与 Keystore 仍依赖 Android，不能宣布直接搬用成功。详见新开发方案的可行性先行步骤。
