## Problem（问题与背景）

- 问题/背景：知芽首页目前没有承载「数据与次级功能」的位置。RikkaHub（`D:\Project\Android\rikkahub-master`，AGPL-3.0）在首页提供侧边抽屉承载会话列表、统计（热力图 + Token 用量）等；用户比对后要求吸收该交互形态，但内容按知芽 IA 重新划界。同时学习场景缺少激励型信息：没有热力图、连续天数等「学得下去」的可视反馈。
- 用户/场景：单人自用，只有用户本人；在首页想快速回到最近对话、看一眼学习热度、进设置。

## Users and scenarios（用户与场景）

- 本期只有用户本人使用；真机体验验收由用户完成。
- 场景：① 打开首页，顶部下方看到最近 14 天热力条与连续天数；② 点左上抽屉按钮，看对话快捷列表回最近主题、看完整热力图与累计指标；③ 从抽屉直达设置。

## Expected outcome（预期结果）

- 预期结果：
  - 首页顶部问候区下方常驻一张迷你热力条（最近 14 天格子 + 连续学习天数），点击进入抽屉。
  - 首页左上抽屉按钮，抽屉承载：对话快捷列表、学习热力图（近若干周）+ 累计指标卡、统计详情入口、设置快捷入口，并预留扩展位（如人设介绍页入口）。
  - 统计数据全部从既有本地记录派生，不新增服务端。

## Core flow（核心流程）

- 核心流程（含中断、撤销、重试）：首页打开 → 热力条随首页加载渲染（无数据时显示空态引导）→ 点抽屉按钮 → 抽屉滑出 → 点对话项直达主题对话 / 点统计详情进完整统计页 / 点设置进设置页；返回或点遮罩关闭抽屉。
- 输入/输出：输入为本地回答记录（时间戳、模型、思考模式等既有列）；输出为按天聚合的活跃统计与抽屉内的快捷导航。
- 状态与异常：无任何学习记录时热力条/热力图显示空态文案，不显示 0 值误导；统计查询失败（本地 DB）按既有数据层错误路径降级，抽屉其余功能不受影响。

## Constraints and non-goals（约束与非目标）

- 约束：
  - Java-only、XML/View；热力图用自绘 View 实现，视觉遵循知芽 design token（生长绿、纸感、44dp 热区）。
  - **抽屉内的对话列表是「快捷入口」不是第二份正典列表**：学习库仍是主题列表与搜索的唯一正典入口；设置仍由底部标签栏承载，抽屉内为快捷入口。不得出现两份各自维护的全量列表（本仓失败案例库「一条规则两个正文」同构坑）。
  - 统计指标只做可从既有记录派生的部分：热力图（按天活跃）、连续学习天数、累计提问数、累计消息数；口径与空态在设计阶段定。
  - 抽屉不承载：搜索（唯一入口在学习库顶部）、助手切换（人设选择在主题内，见 INTENT-2026-09-21-ai-persona-preference）。
- 权衡偏好：激励优先——热力信息外放到首页而不是藏进设置；正典唯一优先——快捷入口不得复制正典数据源。
- 非目标（non-goals）：
  - Token 四指标（输入/输出/缓存节省/总量）**不进本批**：需给回答记录加 usage 列 + 生成链路落库 + 前向迁移（经 `db-migration-reviewer`），另立小批（用户 2026-09-23 拍板）。
  - 不做账号、同步、分享成绩单；不做 Widget/桌面小组件。
  - 不改 V3.2 底部标签栏结构（主页/学习库/设置三 tab 不变）。
  - 不吸收 RikkaHub 抽屉内的搜索聊天、聊天历史全量管理、默认助手切换（吸收矩阵 5.5 reject 结论维持）。
