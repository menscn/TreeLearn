## 1. 聊天主界面

出处：`app/src/main/java/me/rerere/rikkahub/ui/pages/chat/ChatPage.kt`、`ChatList.kt`、`app/src/main/java/me/rerere/rikkahub/ui/components/ai/ChatInput.kt`

- 输入区为常驻底部圆角容器，自上而下：附件预览行、多行文本框、功能按钮行；功能按钮横排可滚动。
- 发送键三态：空输入灰显 → 有内容主题色 → 生成中变为红色停止图标（点按即停止生成）。
- 生成中在消息列表尾部出现加载指示器与处理状态文字；「自动跟随」只在用户位于底部时吸附滚动，手动上滑即中断跟随——这是流式输出与用户阅读权的关键取舍。
- 思维链（reasoning）按时间顺序组成可折叠卡片：生成中自动展开、实时计时滚动，结束后按设置自动收起。
- 长会话进入时弹体积警告；侧边浮条提供到顶/上/下/到底跳转；「预览模式」把全量消息变成带框内搜索的列表，点中高亮并跳回原位。

## 2. 单条消息操作

出处：`app/src/main/java/me/rerere/rikkahub/ui/components/message/ChatMessageActions.kt`、`ChatMessage.kt`、`app/src/main/java/me/rerere/rikkahub/data/model` 相关 ViewModel（`ChatVM.kt`）

- 消息下方常驻一行小图标：复制、重新生成、朗读、翻译、更多（底部抽屉：选择复制、编辑、分享、派生分支、收藏、删除）。
- 重新生成对用户消息需确认弹窗（因为会截断后续），对 AI 消息直接重试——破坏性差异用确认弹窗表达。
- 用户消息气泡可点击直接进入编辑态：内容回填输入框，输入区显示「编辑中」横条可取消；**编辑保存为追加新版本而非覆盖**。
- 生成中删除被阻止并提示先停止生成。

## 3. 消息分支交互（对知芽最有价值的参照）

出处：`app/src/main/java/me/rerere/rikkahub/ui/components/message/ChatMessageBranch.kt`、`app/src/main/java/me/rerere/rikkahub/service/ChatService.kt`、`app/src/main/java/me/rerere/rikkahub/data/model/Conversation.kt`

RikkaHub 的分支有两种来源、两种表达，都没有树状图可视化：

1. **原地分叉（兄弟版本）**：重新生成与编辑都不覆盖旧消息，而是向同一「消息节点」追加新版本并自动切换选中。节点存在多版本时，消息下方出现「← 1/N →」选择器，左右箭头循环切换、到边界时图标半透明；切换即改写当前会话走向，后续消息整体随之切换。
2. **跨会话 fork**：消息菜单「创建分支」把该消息及之前的全部内容深拷贝为一条新会话（标题自动加序号去重），立即跳转到新会话；**没有回到原会话的反向链接**。

值得借鉴的判断：
- 「版本切换器」是一个轻量、可发现性好的多版本表达，适合知芽在同一位置的多次回答（重试/重置）场景。
- 「破坏性动作前置确认 + 非破坏动作直达」的分层值得照搬。
- RikkaHub fork 无来源链接是其模型短板（详见消息分支数据模型规格 V1.0 §4）；知芽的 `BranchSource` 溯源已优于它，不需要向它看齐。

## 4. 设置页与助手（人设）管理

出处：`app/src/main/java/me/rerere/rikkahub/ui/pages/setting/SettingPage.kt`、`ui/pages/assistant/AssistantPage.kt`

- 设置首页按「通用 / 模型与服务 / 数据 / 关于」四组卡片分组，每项「图标+标题+一行描述」，点击进二级页；未配置关键依赖时顶部插入警告卡——把「未完成配置」作为设置页的一级状态。
- 助手列表：搜索 + 标签筛选 chips + 长按拖拽排序（过滤态禁用拖拽）；详情按页签分区（基础/提示词/记忆/参数等）。
- 知芽已有内置人设需求（`Docs/intent/INTENT-2026-09-21-ai-persona-preference.md`）：「详情页签化 + 列表拖拽排序 + 未配置警告卡」三个模式可参照。

## 5. 历史会话与收藏

出处：`app/src/main/java/me/rerere/rikkahub/ui/pages/history/HistoryPage.kt`、`ui/pages/favorite/FavoritePage.kt`

- 历史列表项左滑删除，松手弹带「撤销」的 Snackbar；尾随按钮切换置顶；顶栏提供全局搜索与「清空全部」（确认对话框）。
- 收藏存「会话+消息位置」引用而非内容拷贝：收藏卡片显示来源标题与预览，点击跳回原会话并定位到该消息；左滑删除同样带撤销。
- 「引用而非拷贝 + 跳回定位」与知芽「从稳定回答开子分支」的回溯诉求同构，值得作为知芽收藏/书签类功能的默认形态。

## 6. 与知芽的映射建议（全部待用户拍板）

| RikkaHub 模式 | 知芽映射建议 | 建议取舍 |
|---|---|---|
| 发送键三态（含红色停止态） | 知芽生成中的停止入口 | 建议吸收：状态即按钮，不新增控件 |
| 自动跟随滚动 + 上滑中断 | 流式回答阅读权 | 建议吸收：默认跟随、用户上滑即让位 |
| reasoning 折叠卡（生成中展开计时） | 知芽推理流式披露（T-066 已在做） | 对照查缺：计时与自动收起 |
| 版本切换器 ← 1/N → | 同一位置的多次回答（重试/重置） | 建议吸收，替换自研表达需评估 |
| 破坏性动作确认分层 | 删除/重新生成 | 建议吸收 |
| 未配置警告卡 | 未配置 DeepSeek Key 的设置态 | 建议吸收 |
| 收藏=引用+跳回定位 | 知芽书签/收藏（若立项） | 记入远期，暂不进入 V3.x |
| 历史左滑删除+撤销 | 知芽库列表 | 知芽已有归档语义，仅对照 |

## 7. 真机待办（用户执行后回填结论）

- 思维链卡片折叠/展开与分支切换的动效手感；发送键三态的过渡动画。
- 流式输出时打字占位符的具体呈现与振动反馈。
- 左滑删除的位移阈值、回弹与撤销 Snackbar 的节奏。
- 自动滚动吸附的平滑度与中断灵敏度。
- 长会话（数百条）滚动与历史加载的实际性能。
