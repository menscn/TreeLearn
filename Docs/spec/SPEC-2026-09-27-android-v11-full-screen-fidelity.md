## Requirement spec（需求规格）

- **目标**：将高保真原型 V1.1 的视觉与布局映射到当前 Android 生产界面，覆盖原型中与现有生产路由对应的屏幕、抽屉、弹层和关键状态。这里的「1:1」指视觉层级、位置关系、尺寸比例、颜色、字体、间距、卡片、圆角、阴影、图标与动效一致；Android 仍按原生布局与设备密度适配。
- **范围**：应用外壳与底部三标签；首页；首页抽屉；统计详情；学习库的进行中、已完成与搜索状态；对话页与输入栏、模型选择器、来源卡、选中文字菜单等面板；学习树画布；分支导航；设置中心；提供商列表与编辑状态；模型设置；搜索服务与引擎详情；语音设置；文件管理；这些页面上的空、加载、错误、禁用、生成中与确认状态。
- **已确认边界**：允许调整现有控件布局；保留当前功能、数据、操作及导航结果；不新增只存在于原型、但当前 Android 未提供的能力。原型自带演示数据只用于理解视觉状态，不写入用户设备；不同数据导致的内容差异不作为样式 Gap。
- **规格接受记录**：用户于 2026-09-27 回复「接受」；统计区间选择 A，见「疑虑点」决策记录。
- **非目标**：不改数据库、业务规则、权限和外部服务契约；不新增导航能力或独立入口；不引入依赖、Kotlin 或字体文件；不改设计 token 数值；不仿造 Android 系统状态栏/导航栏。系统区域使用原生呈现并避让安全区。
- **验收方向**：按同设备视口和对应数据/交互状态逐屏截图对照；画面无截断、遮挡或横向溢出；现有可点击区域不小于 44dp；手机与现有 sw600dp 横屏布局均保留。实现任务另行记录构建、回归、真机截图和 Java-only / token 守门结果。
- **当前并行工作**：首页已有视觉规格与 `T-2026-09-27-001` 至 `008` 任务链，暂不重开或覆盖；本规格覆盖其余页面，并在首页任务收尾后只补核尚存差异。任务状态以 `.codex/tasks/` 当前文件为准。
- **事实来源**：原型走查记录 `artifacts/evidence/ux-v11-prototype-2026-09-27.txt` 记录 24/24 步通过且页面异常为零；当前 Android 映射以 `android/app/src/main/java/com/treelearn/app/MainActivity.java` 及对应 `screen/`、`res/layout/` 生产代码为准。V1.1 的视觉意图不覆盖生产路由与行为事实。

## Interface plan（界面方案）

### 屏幕映射与 Gap

| 区域 | 原型视觉 / 状态 | 当前 Android 映射 | 审计结论 |
| :--- | :--- | :--- | :--- |
| 全站共用底纹 | 所有 `.screen` 均使用纸色底与横向细线背景 | `activity_main.xml`、`screen_home.xml`、`PaperRuleBackdrop` | **明确 Gap**：Android 外壳当前为纯底色；`PaperRuleBackdrop` 只挂在首页手机/平板布局，其他路由没有共用纸纹层。应复用同一底纹绘制逻辑，并避免首页叠画。 |
| 应用外壳、首页 | 底部主页/学习库/设置；首页品牌、输入卡、双轨推荐、主题卡 | `MainActivity`、`HomeScreen`、`screen_home*.xml` | 首页专属视觉复刻已有规格及进行中任务；完成前不判本项通过，也不重复改写。全局安全区须按当前构建截图复验。 |
| 首页抽屉 | 标题与关闭入口、月历热力卡、最近学习快捷行 | `HomeDrawerScreen`、`drawer_heatmap.xml` | 生产代码已有关闭按钮、月度热力卡与最近学习行，结构对应；因设备无主题/统计数据，数据态样式暂不能据真机确认。 |
| 统计详情 | 三张累计指标卡在前，后接当前月份的 7 列月历热力卡 | `StatsDetailScreen`、`screen_stats_detail.xml`、`StatsDetailPresenter` | **明确 Gap**：现有 XML 先放热力图，再放指标卡；网格是十周数据的横向滚动视图，而原型是月历卡。不是「缺少热力图」；T-104 证据与当前源码均显示热力图已实现。用户选择 A：详情页只显示当月；历史数据和共享统计聚合保持不变，不保留十周可视窗口。 |
| 学习库、搜索 | 标题、顶部搜索、进行中/已完成分段及卡片；搜索原型展示独立搜索页布局 | `LibraryScreen`、`screen_library_body.xml`、`SearchPage` | 列表与分段已映射；Android 搜索结果在 `LibraryScreen` 内替换列表，原型则绘制带标题、范围说明与结果卡的独立视觉页面。复刻其搜索画面时沿用现有路由与返回结果，不新建生产导航入口。 |
| 对话、弹层 | 消息与回答、思考过程、回答操作行、推荐追问、来源卡、输入栏；模型选择器、分支列表、引用/附件/搜索面板及确认层 | `ChatScreen`、`screen_chat_body.xml`、`item_chat_message.xml`、相关 popup/sheet 类 | 源码与布局正在承接对话视觉变更；没有有效的当前对话页真机截图：`android-chat-batch-abc-2026-09-27.png` 实际是首页，且设备未配置 Key，不能进入有效发送/回答状态。现阶段不声称 1:1 已验证。 |
| 学习树、分支导航 | 画布上的根、枝、叶与标题牌；导航页呈现祖先、当前分支和子分支 | `TreeCanvasScreen`、`TreeCanvasView`、`NavigationScreen`、`screen_tree*.xml`、`screen_navigation*.xml` | 既有截图评审指出单主题新树缩至几乎不可识别；该画布比例/默认视口是已知 Gap，需按原型复核。当前设备无学习主题，导航与有分支画布状态无法安全实测。 |
| 设置中心与子页 | Key 与能力配置入口；提供商列表/编辑、三分工模型与思考预算、搜索引擎列表/详情、语音试听、文件列表/清理 | `SettingsScreen`、`ProviderAdminScreen`、`ModelSettingsScreen`、`SearchServiceSettingsScreen`、`VoiceSettingsScreen`、`FileManagerScreen` | 生产页面均有对应组件。已找到原型页面与 Android 路由映射，但缺少同状态、同视口的归档对照截图；本轮不把组件存在或功能测试当成视觉一致证据。旧交互评审中与 V1.1 用户裁决冲突的建议（例如一级设置标题去重）不沿用。 |

### 视觉落地原则

- 页面结构以 V1.1 对应屏幕为基准；控件可以重排，但保持用户已确认的功能、数据操作和返回/跳转结果。
- 设计 token 只引用项目权威源 `Docs/04-ux-design/知芽-TreeLearn-高保真原型-v1.html` 的 `:root`，机器镜像与 Android 资源分别由既有 token 守门校验；本规格不抄录或另造色值、字号、间距档位。
- 正文使用系统 sans-serif，品牌与标题按原型现有衬线回退；不打包字体。原型 hover 仅映射为 Android 按压反馈。
- 搜索与已完成视图沿用学习库容器；提供商编辑沿用生产现有页面/状态组织；视觉映射不强迫生产新增原型中的独立路由。
- 数据为空时按生产空态展示，不载入原型示例内容；对话、树、搜索命中等有内容状态只能使用不影响用户数据的隔离验证方式。
- 对每个屏幕分别复核状态栏避让、滚动、键盘弹出、弹层翻转/遮罩、窄屏换行、平板横屏与触达面积；不以全局颜色一致代替逐屏视觉核对。

## Technical spec（技术规格）

- **界面承载**：继续使用 Android Java/XML 与现有自绘 View；不把 HTML 原型嵌入 WebView，不新增依赖，不改 Activity/Presenter 的业务职责。
- **页面路由**：`MainActivity` 是现有生产入口事实。搜索通过 `LibraryScreen.showSearch` 呈现，统计从抽屉进入，学习树与分支导航通过当前主题/分支进入；视觉实现不得新增、删除或改写这些导航结果。
- **数据**：统计继续读现有统计聚合；热力图视觉区间的裁决见「疑虑点」。学习库、抽屉、文件和聊天内容继续由现有数据端口驱动，不复制原型示例作为默认生产数据。
- **兼容与无障碍**：保持系统状态栏/显示缺口安全区处理、现有无障碍描述及至少 44dp 触达区域；保留 `layout-sw600dp` 平板横屏适配。
- **代码路径索引**：`android/app/src/main/java/com/treelearn/app/MainActivity.java`、`android/app/src/main/java/com/treelearn/app/screen/`、`android/app/src/main/res/layout/`、`android/app/src/main/res/values/`。生产差异以这些路径的当前内容复核，历史截图仅作时间点证据。
- **来源**：原型 V1.1「V1.1 增量走查路径」与对应渲染函数；Android 当前页面路由见 `MainActivity`，各页面布局见上述 `screen/` 与 `layout/`。

## Doubts（疑虑点）

- **拍板记录（2026-09-27，用户选择 A）**：统计详情按原型呈现当前月份月历；底层历史数据与现有统计聚合不删除、不改写。代价已接受：统计页只展示当月，较早日期不在该页可见。
- **疑虑 2：有效对话页截图**（冲突对象：原型有回答/生成/来源卡状态，当前设备缺少 Key 且没有可进入的有效主题；建议实现验收使用隔离数据环境，不写用户设备；代价是需要另备无用户数据的验证环境；用户无需在个人设备配置 Key）。
- **明确不作为疑虑的事项**：首页热力条不纳入本版（原型 V1.1 与首页视觉规格一致）；原型旧版独立归档路由不重新加入；系统状态栏继续由 Android 原生显示；空态与原型演示数据不同属于数据态差异，不是视觉实现 Gap。
