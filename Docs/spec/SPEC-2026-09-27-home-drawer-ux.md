# 首页与侧边栏交互设计

## 需求规格

- 首页主区域按 A 方向落地：中心品牌区在顶部，缩小后的主标语之后先呈现上下双轨推荐学习，输入框作为主操作，最近学习固定在页面底部。**[顺序部分已被取代]** 用户 2026-09-27 拍板首页版式顺序改按原型，即品牌 → 主标语 → 输入卡 → 推荐区 → 历史主题；本条的「推荐先于输入框」不再生效，顺序正文以 [SPEC-2026-09-27-home-visual-fidelity.md](SPEC-2026-09-27-home-visual-fidelity.md) 为唯一出处。
- 侧边栏继续由首页左上角菜单按钮打开，点击遮罩、返回键或侧边栏入口后按现有生命周期关闭。
- “最近学习”必须呈现为有层次的历史列表，而不是只有一条孤立文本；每条记录显示可识别的主题标题，并保留点击后恢复原学习位置的行为。
- 热力图归入侧边栏的“学习热度”区域，移除首页中的热力图展示；统计数据继续使用现有统计读取口径，不新增第二套数据源。
- 移除侧边栏设置按钮；设置统一通过底部标签栏进入。热力图本身作为统计详情入口。
- 侧边栏内容控制在固定高度内，不使用中段嵌套滚动；历史摘要限制为固定条数，更多记录统一进入学习库。
- 推荐学习固定为两行：上行向左滚动、下行向右滚动；按下任一行暂停，松手后延迟恢复。

## 界面方案

- 抽屉顶部使用“学习概览”标题与关闭图标。
- “最近学习”区域使用纵向历史行：每行只显示真实主题标题，并使用整行点击恢复对应分支；没有历史时不添加解释性占位文字。
- 热力图位于“最近学习”标题上方，显示“学习热度”和当前月份，使用周一至周日的标准 7×6 月历网格；卡片宽度充分利用侧边栏内容区，不再把小网格固定在卡片中央。热力图卡片本身可点击进入完整统计页，不再出现“学习统计”文字按钮。
- 热力图使用当前月份的真实日期位置，月初和月末用空白格补齐矩形；无最近历史时显示一行轻量空状态，不留下整块空白。
- 抽屉保留遮罩层和左侧面板视觉关系，面板内部采用现有纸感浅色主题和设计 token，不新增临时颜色或尺寸值。
- 抽屉不设置中段纵向滚动容器；通过压缩热力图、限制历史摘要条数和单行高度，保证热力图、历史摘要与设置入口在面板内同屏。

## 技术规格

- 修改 `HomeScreen` 的布局结构：放大 Logo 与软件名置于缩小后的标语上方，推荐学习先于输入框，最近学习位于输入框之后；推荐区使用上下双轨反向横向滚动，历史最多展示三条并按统一间距排列。**[顺序与历史条数部分已被取代]** 「推荐学习先于输入框」不再生效，顺序正文以 [SPEC-2026-09-27-home-visual-fidelity.md](SPEC-2026-09-27-home-visual-fidelity.md) 为唯一出处；品牌区「Logo 与软件名」按原型改为横排。「历史最多展示三条」自 2026-10-23-074 起同样不再生效：首页历史主题区画出读取结果的全部条目，与区头计数是同一条列表——上限让页面写成「6 个」只画 3 张卡，且列高低于 `ScrollView` 自身时该视图报告「不能滚动」，整页拖不动（真机缺陷；Web 侧 `HomePage.tsx` 从来不截断）。**本条只取代首页**：抽屉的最近学习仍是固定条数的快捷面，见下「界面方案」与 `android/README.md` 的 `screen.HomeDrawerScreen` 行。
- 修改 `HomeDrawerScreen` 的绘制结构：移除中段滚动容器，增加“学习概览”标题与关闭入口，历史行复用现有 `LibraryViewState.Row` 数据，新增当前月份标准 7×6 日历热力图区域与空历史状态。
- 修改 `HomeDrawerPresenter` 的状态，使侧边栏一次读取最近主题与统计快照；最近主题继续通过 `QuickTopicsSource` 读取，热力图继续通过现有 `HomeData`/`HomeStore` 统计端口读取。
- 删除首页 `HomeScreen` 对热力图展示和点击入口的绑定，但不删除统计领域模型、统计详情页或其测试。
- 设置入口不在侧边栏重复承载，继续由底部标签栏提供；热力图使用可点击容器承载统计入口，文字只作为可见标签和无障碍文本。
- 同步手机布局与 `layout-sw600dp` 宽屏布局，确保抽屉列表、统计区和图标按钮在两种配置下结构一致。
- 保持 Java-only 约束，不新增 Kotlin、AndroidX 或第三方依赖；保持现有抽屉关闭、返回导航和主题行点击行为。
- 验收覆盖：首页空态/有历史、推荐横向滚动、统计有数据/空数据/读取失败、内容超长、设置入口、统计入口、返回键优先关闭抽屉，以及手机与宽屏布局。

## 疑虑点

- 侧边栏中的热力图采用现有统计聚合结果映射到当前月份，不新增第二套数据源；完整统计由热力图卡片点击打开。
- 最近学习列表继续受现有快捷列表上限约束，不在抽屉内复制学习库的搜索、归档或完整列表能力。
- 设计稿中的状态栏属于系统窗口区域，本轮只确保内容不覆盖状态栏，不伪造一套应用内状态栏。
- 如果统计读取失败，抽屉仍显示最近学习；隐藏热力图，不添加失败说明文字。设置继续由底部标签栏进入。
