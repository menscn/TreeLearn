# 知芽（TreeLearn）1.0.0 更新说明

发布日期：2026-10-20
版本号：1.0.0（versionCode 1000000）
安装包：`android/app/build/outputs/apk/release/app-release.apk`
适用设备：Android 13 手机（minSdk 28）

本说明描述本次侧载构建实际包含的用户可见变化；证据见 `artifacts/evidence/` 下 2026-10-20 的构建、真机与 Web 走查记录。

## 新增功能

- 新增 Web 版 13 屏预览：设置、提供商管理、模型设置、搜索服务、语音、文件管理、分支导航、树状总览、学习库、首页抽屉等页面与手机版使用同一份真机结构数据，可逐屏查看并完成主要换屏操作。该预览为本地单文件产物，不需要联网加载资源。
- 分支导航新增未命名分支的名称：还没生成标题的子分支，在列表里显示为「未命名分支」，不再是一行空白。

## 修复问题

- 修复主题下存在未命名子分支时，分支导航整屏提示「本机数据读不出来」的问题；导航仍能列出整棵树，读失败的原因也会写入日志。
- 修复首页历史主题卡片在刷新时重复播放入场动画、动画过程中点不开的问题；重新绘制后卡片保持可点击，且不会再次重播。
- 修复回答生成阶段被旧轮次覆盖的问题；生成状态只由存储中的当前记录决定，避免界面回退到上一阶段。

## 优化体验

- 分支导航与树状总览在读取失败时保留上一次可用内容，并把失败原因记录到 `TreelearnUi` 日志，便于现场定位。
- 发布前在真机完成全量仪器回归：301 例、0 失败；随后重新安装正式包并完成首页、设置页冒烟。
- Web 版在 Edge 与 Chromium 两个浏览器环境完成 24 步全量走查，29 项判定全部通过，控制台 0 错误。

## 已知边界

- Web 版为预览形态，不包含本机服务、PC 外壳与平板横屏布局。
- 本次不包含真实 AI 发送测试；API Key 仍由使用者在设置页自行配置。
- AI 人设与「我的森林」不在本版本范围内。
