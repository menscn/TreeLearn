What was done
-------------
To manufacture a compile-only RED without a device, the five T-005 production classes were moved
from the shared repository to %TEMP%\t005-red-stash with Move-Item. This file recorded their
SHA-256 values so the move could be verified and reversed.

Why it must not be repeated
---------------------------
Removing files from the shared working tree made the whole repository unbuildable for every other
lane: `:app` main (AiGatewayStreams imports com.treelearn.data.secret) and `:data` unit tests both
failed on missing symbols, and two lanes had to restore the files byte-for-byte
(T-009-crosslane-stash-recovery.txt, T-008-crosslane-stash-recovery.txt). The correct method is to
run the RED experiment on a scratch COPY of the module outside the repository.

Verified outcome
----------------
The repository is intact: every file above is present and its SHA-256 prefix still matches the
value listed here, which is the same value the restoring lanes produced. %TEMP%\t005-red-stash
still holds identical duplicate copies and can be discarded whenever convenient.
