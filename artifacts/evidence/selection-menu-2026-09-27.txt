[2026-09-27] 划词菜单改为应用自绘 + 「新建分支」改名「新建主题」
direct execution（无 Harness task）—— 用户拍板 2026-09-27

== 变更的运行时事实 ==
1. 长按选中回答文字后：原生选择手柄保留（textIsSelectable + 平台 ActionMode），平台自带的划词工具条
   （全选 / 复制 / 平台翻译…）在 ChatScreen.Row.SelectionMenuCallback 里被清空，菜单改由 WordMenuPopup
   绘制，四项固定为 追问 / 新建主题 / 复制 / 全选（顺序取自 WordMenu.Item：QUOTE, FORK, COPY, SELECT_ALL）。
   起因：平台工具条无法由应用排序，应用追加的项永远排在系统项之后，「新建分支」因此被挤进「更多」。
2. 文案：chat_act_fork / cd_act_fork / chat_fork_title / chat_suggestion_fork_title 由「新建分支」改为「新建主题」，
   三处入口（划词菜单、回答底部操作行、推荐问题旁分叉热区）读同一组字符串。
3. 新增：WordMenuPopup.refresh()（拖动选区手柄时卡片与「选中「…」」标签跟随），WordMenuPopup.setOnClosed()
   （卡片关闭即结束平台选择，手柄与菜单同生同灭），ChatScreen.showWordMenu/dismissPopups 统一管理两张卡片。
4. 删除：values/ids.xml 的 chat_selection_quote / chat_selection_fork（不再往平台菜单加项）；
   ChatScreen.Row.hasSelection()（唯一调用方是被删掉的平台菜单回调）。
